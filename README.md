# Traveller RPG App

A reference and character management app for Mongoose Traveller 2nd Edition (2022).

## Features

- Character sheets (per-player, shared with referee)
- Character creation wizard
- Skills, tasks, and combat reference
- Spacecraft sheets and operations
- Space combat tracker
- Trade calculator

## Tech Stack

- Plain HTML / CSS / JavaScript frontend
- Supabase (database, real-time sync, authentication)
- Hosted via GitHub Pages

## Sections

1. Character Sheet
2. Character Creation
3. Skills / Tasks / Combat
4. Spacecraft Sheet
5. Spacecraft Expenses
6. Spacecraft Operations
7. Space Combat
8. Trade
